# Инструкции для агентов

## Стек

Kobweb 0.25.1 (Kotlin/JS, Compose-подобный DSL поверх HTML), фронтенд-only.
Код сайта — `site/src/jsMain/kotlin/io/github/zelenyy/`, статьи —
`site/src/jsMain/resources/markdown/`, статика (видео/картинки) —
`site/src/jsMain/resources/public/`.

## Не углубляться в анализ библиотек Kobweb

Не распаковывать и не изучать `-sources.jar` / `.klib` из `~/.gradle/caches` ради поиска API.
Вся нужная информация собрана в [docs/kobweb-api.md](docs/kobweb-api.md): модификаторы и их
сигнатуры, единицы, цвета, `CssStyle`/брейкпоинты, DOM-хелперы, особенности рендеринга markdown.

Правила:

1. Сначала открыть `docs/kobweb-api.md`, потом писать код. Если ответ там есть — никаких
   дополнительных поисков по исходникам библиотек.
2. Если нужного API в шпаргалке нет — не проводить глубокий разбор библиотеки. Достаточно одного
   прогона компиляции / `kobweb build` или одного точечного поиска. Неизвестное имя enum'а или
   модификатора дешевле подобрать итерацией сборки, чем чтением исходников.
3. Универсальный escape hatch, когда типизированного модификатора нет:
   `Modifier.styleModifier { property("css-name", "value") }`.
4. Новое полезное знание об API дописывать в `docs/kobweb-api.md`, чтобы в следующий раз его не
   переисследовать.

## Прочее

- Комментарии в коде и ответы — на русском (проект русскоязычный).
- Правки минимальные, строго в рамках задачи. Не трогать соседние виджеты и лейауты «заодно».
- Не откатывать и не переписывать файлы без явного указания.
